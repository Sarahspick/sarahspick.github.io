# 레퍼런스 분석: 겜토리 쇼츠 2편

분석 대상 (업로드 파일, 메타데이터 기준 채널 = 겜토리)

| # | 제목 | 길이 | 소재 |
|---|------|------|------|
| 1 | 게임 역사상 가장 낭만적인 서버 종료 | 53.6초 | 파이널 판타지 14 구버전 종료 이벤트 |
| 2 | Ai에게 숨바꼭질을 시키면 생기는 일 | 47.3초 | OpenAI 멀티에이전트 숨바꼭질 연구 |

> 채널 페이지와 쇼츠 링크 2개는 이 클라우드 환경에서 youtube.com 접속이 차단돼(프록시 403) 직접 열지 못했습니다. 업로드된 두 파일이 같은 채널 영상이라 이것으로 프레임 단위 분석을 했습니다.

분석 방법: 1초 간격 전체 프레임 + 훅 구간 0.2초 간격 프레임, 미디어 영역 장면전환 검출(ffmpeg scene), 자막 영역 변화 시점 검출, 음량(EBU R128) 타임라인, 스펙트로그램, 음성인식(SenseVoice)으로 나레이션 존재 확인.

## 1. 화면 구성

커뮤니티 게시글 모바일 화면을 흉내 낸 **고정 틀**이 영상 내내 유지됩니다.

- **상단 바 (0~8%)**: 아이콘(북마크 / 게임패드) + 채널명 `겜토리`(굵은 고딕, 가운데) + `⋮`. 영상1은 연보라(#A3A8D8), 영상2는 진파랑(#4A6CA8)으로 **영상마다 색만 교체**.
- **게시글 제목** (굵게, 좌측 정렬) + 메타 줄 `작성자 | 18:20 | 조회 999,999` + 구분선.
- **본문 = 자막 영역**: 가운데 정렬, 최대 2줄, 검정 단색.
- **미디어 영역**: 가로를 꽉 채움. 영상1은 16:9 그대로, 영상2는 **4:3으로 크롭**해 피사체를 크게.
- **하단 약 30%는 비워 둠**: 유튜브 UI(제목, 구독 버튼)가 덮는 자리.

## 2. 훅 (0~2.2초)

1. 첫 프레임부터 **썸네일 겸 훅 화면**: 전체를 약 70% 어둡게 깔고 상단에 **초대형 2줄 제목**(1줄 흰색, 2줄 강조색, 두꺼운 검정 외곽선).
2. 미디어에는 **가장 자극적인 장면 + 빨간 굵은 화살표**가 핵심 대상(붉은 달, 경사로)을 가리킴.
3. 나레이션이 **제목을 그대로 읽음**. 동시에 0.5~0.8초 지점에 굵은 타격 효과음(스펙트로그램상 전 대역 트랜지언트).
4. 2.0~2.2초에 일반 레이아웃으로 **하드컷**, 첫 문장 시작.

## 3. 자막과 나레이션

- AI 나레이션이 자막을 한 줄씩 그대로 읽고, 배경음악이 계속 깔림(음량 약 -20 LUFS로 일정).
- 자막은 **문장 단위 누적형**: 1줄이 뜨고 → 약 1.5~1.8초 뒤 2번째 줄 추가 → 다음 문장에서 초기화.
- 자막 변화 간격 평균 약 1.6초. 말투는 반말 구어체(“~했는데”, “~했음”, “~버림”).

## 4. 컷 편집

- **문장이 바뀌는 순간 클립도 바뀜**(컷 = 문장 시작). 영상1은 53초 동안 미디어 컷 25회, 평균 샷 약 2초.
- 전환 효과 없음, 전부 **하드컷**.
- **증거 삽입**: 메타크리틱 점수 캡처(49점), OpenAI 블로그 그림 캡처를 천천히 줌/팬.
- **포인터**: 흰 마우스 커서가 대상을 가리킴(영상2, 21초).
- 엔딩: 영상1은 마지막 3초에 틀을 없애고 영상만(여운), 영상2는 열린 질문(“앞으로 세상이 어떻게 바뀌려는 걸까?”).

## 5. 스토리 공식

1. **훅**: 결과나 이상한 장면을 먼저 (“가장 낭만적인 서버 종료”)
2. **배경**: “이 게임은 점점 망해가고 있었는데”
3. **고조**: 이상 징후가 점점 커짐 (붉은 별이 다가옴 → 자면 세상이 멸망하는 이벤트)
4. **클라이맥스**: “뜬금없이 시네마틱이 재생됐는데…”
5. **반전**: “알고 보니 섭종이 아니라 리메이크를 위한 빌드업” / “더 놀라운 점은 6년 전에 공개한 내용”
6. **여운 또는 질문**

## 6. 소스 출처

게임 공식 트레일러·시네마틱, 유저 플레이 영상, 공식 블로그(OpenAI) 영상·이미지, 리뷰 사이트 캡처. 원본을 그대로 쓰지 않고 **크롭 + 나레이션 + 자막 + 스토리 재구성**을 더하는 구조.

## 7. 우리 채널에 적용한 것

| 레퍼런스 | 적용 |
|---|---|
| 커뮤니티 게시글 틀 | 채널 크롬은 빼고 **클래식 레이아웃**: 같은 영상을 흐리게 깐 배경 + 가운데 1:1 영상 + 상단 고정 제목 |
| 단색 2줄 자막 | 1~3단어씩 **큰 외곽선 자막**, 핵심 단어 노란색, 단어 타이밍에 정확히 맞춤 |
| 어둡게 + 초대형 제목 + 빨간 화살표 훅 | 첫 문장부터 빨간 화살표 + 타격음, 상단 제목이 곧 썸네일 문구 |
| 문장 = 컷 | 동일. 줄 단위 컷도 지원(`clips` 배열), 평균 샷 약 2초 |
| 캡처 증거 삽입 | 출처·날짜가 적힌 **인용 카드** + CLASSIFIED / DROPPED 도장 |
| 효과음 | 실제 다운로드한 효과음만 사용, **단어 단위로 정확히 배치** |
| 반전 | 모든 대본에 "But here's the twist" 구조 |
| AI 나레이션 | Microsoft 뉴럴 음성(Brian), +20% 빠르게 |
