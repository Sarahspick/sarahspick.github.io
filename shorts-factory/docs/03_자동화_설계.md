# 자동화 설계

## 1. 전체 흐름

```
[1 소재 발굴]        [2 대본]              [3 빌드]            [4 렌더]                 [5 납품]
mine.py        →   stories/catalog.py →  stories/json/   →  engine.py + audio.py →  ~/Downloads/야생CCTV
희귀종·사건·근접      훅 제목, 비트별 자막     사진 경로·초점박스     1080×1920, 30fps           MP4 + 업로드_정보.csv/md
contact sheet        (사람 또는 LLM)         고정 (재현 가능)       자동 줌·HUD·자막·효과음
```

1. **소재 발굴**: 269만 건 촬영 기록에서 희귀종, "초식동물 → 몇 분 뒤 포식자", 렌즈 코앞 근접 사진, 한 카메라의 전 종 몽타주, 화재를 자동으로 찾고 10% 격자가 그려진 contact sheet를 만듭니다.
2. **대본**: 사진을 보고 비트(화면 단위)마다 자막, 카메라 워크, 전환, 효과음을 적습니다. 사실 확인은 메타데이터(촬영 시각, 마릿수, 행동)로 합니다.
3. **빌드**: 대본을 사진 경로와 바운딩 박스가 들어간 JSON으로 고정합니다. 이 JSON만 있으면 메타데이터 없이도 같은 영상을 언제든 다시 만들 수 있습니다.
4. **렌더**: 프레임마다 Pillow로 화면을 합성해 ffmpeg로 바로 인코딩합니다. 오디오는 효과음·음악·주변음을 합성해 2패스 음량 정규화(−14 LUFS)까지 자동입니다. 4코어 기준 한 편 약 1~2분, 30편 약 10분.
5. **납품**: 영상과 함께 업로드용 제목, 설명란(출처·라이선스 포함), 고정 댓글, 태그가 CSV와 Markdown으로 나옵니다.

## 2. CapCut 마우스 자동화 대신 코드 편집을 택한 이유

1. 이 작업은 클라우드 환경에서 돌아가서 사용자 PC의 CapCut이나 다운로드 폴더에 직접 접근할 수 없습니다.
2. CapCut은 공식 편집 API가 없고, 마우스 좌표로 조작하면 UI 업데이트·팝업·해상도 차이에 쉽게 깨집니다. 30편을 무인으로 돌리기엔 실패 지점이 너무 많습니다.
3. CapCut에서 하던 편집 요소(자막 스타일, 강조색, 줌인·팬, 흔들림, 전환, 효과음, BGM, 음량 맞춤)를 전부 코드로 구현했습니다. 같은 입력이면 항상 같은 결과가 나오고, 여러 편을 동시에 만들 수 있습니다.
4. 손으로 다듬고 싶은 편은 완성된 MP4를 CapCut에 넣고 이어서 편집하면 됩니다.

## 3. 완전 무인화 로드맵 (다음 단계)

현재 사람 손이 필요한 곳은 2단계(대본) 하나입니다. 이 부분도 자동화할 수 있습니다.

1. `mine.py`가 만든 contact sheet와 메타데이터를 Claude API(이미지 입력 지원)에 넣고, `catalog.py` 형식의 비트 목록을 JSON으로 받습니다. 이번 30편의 대본이 그대로 예시(few shot)가 됩니다.
2. 자동 검수: `preview` 시트를 다시 모델에 보여 주고 "자막이 동물을 가리는지, 사진에 없는 내용을 말하는지"를 체크합니다. 이번 작업에서 실제로 걸러낸 오류 유형(동물이 화면 밖으로 잘림, 사진과 안 맞는 자막, 확인 안 된 숫자)이 체크리스트입니다.
3. 업로드: YouTube Data API(`videos.insert`)로 예약 업로드. 기본 할당량(하루 10,000 단위, 업로드 1회 1,600 단위) 기준 하루 약 6편까지 가능합니다. 채널 소유자 본인의 OAuth 인증이 필요합니다.
4. 예약 실행: 매일 정해진 시간에 1~3단계를 돌리는 스케줄러(Windows 작업 스케줄러, macOS launchd, 또는 클라우드 예약 작업).

사실 확인이 필요한 정보 카드(숫자·생태 지식)는 완전 자동화 후에도 발행 전에 사람이 한 번 훑어보는 것을 권장합니다.

## 4. 이번 작업에서 발견한 품질 규칙

1. 첫 화면은 가장 센 장면 + 충격음 + 흔들림. 설명은 두 번째 비트부터.
2. 동물이 화면 아래쪽에 있으면 자막을 위로 올린다 (엔진이 자동 판단).
3. 자막은 두 줄 이내, 쉼표 뒤에서 줄바꿈, "박을 듯이"처럼 의존명사는 붙여 쓴다 (엔진 규칙).
4. 사진에 안 보이는 것은 말하지 않는다. 예: 하이에나가 렌즈에 얼굴을 들이민 사진에 "카메라를 물었다"라고 쓰지 않는다.
5. 촬영 시각·간격(“3분 뒤”, “90초 뒤”)은 메타데이터 그대로 쓴다. 이게 이 채널의 신뢰도이자 무기다.
