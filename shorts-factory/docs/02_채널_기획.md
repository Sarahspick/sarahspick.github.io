# 채널 기획: 야생CCTV

> 사람이 없을 때, 야생은 진짜 모습을 보여준다.
> 세렝게티 무인카메라에 찍힌 실제 사건들을 파헤칩니다.

## 1. 한 줄 컨셉

겜토리가 "게임보다 재미있는 게임 사건"이라면, 야생CCTV는 **"다큐보다 재미있는 무인카메라 사건"** 입니다.
탄자니아 세렝게티 국립공원에 설치된 무인카메라 225대가 7년 동안 찍은 710만 장의 실제 사진에서 사건을 골라 이야기로 엮습니다.

| 항목 | 제안 |
|---|---|
| 채널명 | 야생CCTV |
| 핸들 | @야생CCTV (선점 불가 시 @wildcctv.kr) |
| 소개 문구 | 사람이 없을 때 찍힌 야생의 진짜 모습. 세렝게티 무인카메라 사건파일을 매일 공개합니다. |
| 시리즈명 | 사건파일 #01, #02 … (번호가 쌓이면 정주행 유도) |
| 타깃 | 동물·자연·미스터리 쇼츠를 보는 한국 10~40대 |

## 2. 왜 이 소재인가

1. **실제 영상이다**: AI 생성 장면이 하나도 없습니다. 연구용 무인카메라가 찍은 진짜 사진입니다.
2. **합법적으로 쓸 수 있다**: Snapshot Serengeti 데이터는 CDLA Permissive 1.0 라이선스로 공개되어 상업적 이용과 수정이 허용됩니다. 출처는 설명란과 화면 하단에 표기합니다.
3. **사건이 들어 있다**: 사진마다 촬영 시각, 카메라 위치, 동물 종, 마릿수, 행동(사냥·새끼 동반 등) 메타데이터가 있어서 "물소가 달리고 3분 뒤 사자가 돌아왔다" 같은 **시간순 스토리**를 사실 그대로 만들 수 있습니다.
4. **무한 공급**: 266만 건의 촬영 기록, 61종. 희귀종(검은코뿔소 71건, 표범 410건), 초원 화재, 대이동 같은 소재가 계속 나옵니다.
5. **겜토리 공식이 그대로 먹힌다**: 호기심 제목 + 반전 + 감정어. 레퍼런스 분석에서 감정어·최상급 제목의 조회수 중앙값이 전체의 약 2배였습니다.

## 3. 영상 포맷 (30편 공통)

```
┌──────────────────────────┐
│ ● 야생CCTV 사건파일 #07    │  태그라인
│  0.003% 확률로 찍힌        │  2줄 훅 제목 (Black Han Sans, 강조어 노란색)
│  검은코뿔소                │  영상 내내 고정
├──────────────────────────┤
│ ● REC   2011.07.13 17:21 │  CCTV 모니터 (1080×1080)
│                          │  실제 촬영 시각이 흐르는 타임스탬프
│      [사진이 연속 재생]     │  자동 줌 / 팬 / 흔들림
│   [ 검은코뿔소 ▼ ]         │  동물 이름표
│  렌즈 코앞까지 왔다         │  자막 (고딕 블랙, 강조어 노란색)
│ CAM G12  SERENGETI       │
├──────────────────────────┤
│ 영상 출처: Snapshot Serengeti · LILA BC │
└──────────────────────────┘
```

| 요소 | 방식 |
|---|---|
| 규격 | 1080×1920, 30fps, H.264, AAC 192k, 음량 −14 LUFS (YouTube 기준) |
| 길이 | 18~45초 (평균 약 25초) |
| 첫 1초 | 가장 강한 장면 + 충격 효과음 + 화면 흔들림 (스크롤 멈춤용) |
| 사진 재생 | 무인카메라 연사 3장을 셔터음과 함께 플립북처럼 재생 |
| 카메라 워크 | 동물 위치(바운딩 박스 또는 연사 차이 분석)로 자동 줌인·줌아웃·팬 |
| 전환 | 되감기(VHS), 지지직 노이즈, 플래시, 페이드 |
| 강조 | 빨간 원, 동물 이름표 팝업, 정보 카드(숫자 팩트) |
| 결말 | 정지화면 + 질문형 자막 → 댓글 유도, 루프 재시청 |
| 사운드 | 효과음 12종, 분위기별 BGM 6종(긴장·미스터리·귀여움·웅장·슬픔·코믹), 주변음(낮 새소리·밤 풀벌레·불 타는 소리) **전부 코드로 직접 합성** → 저작권 걱정 없음 |

## 4. 제목 공식

1. 감정어·최상급: "세상에서 가장 {겁 없는} 동물", "사자도 무서워하는 {검은 죽음}"
2. 숫자 훅: "0.003% 확률로 찍힌 {검은코뿔소}", "150만 마리가 {카메라 앞을} 지나가면"
3. 반전: "하이에나인데 {흰개미}만 먹는다", "돼지가 아닌데 {땅돼지}라 불리는 동물"
4. 상황극: "카메라가 {사자 무리} 한가운데 떨어졌다", "기린을 찍으려 했는데 {다리만} 찍혔다"

화면 제목은 짧게(2줄), 업로드 제목은 조금 길게 + ㄷㄷ/ㅋㅋ (레퍼런스에서 효과 확인).

## 5. 업로드 운영

1. 하루 1~2편, 저녁 6~9시(한국시간) 권장. 30편이면 약 3~4주 분량.
2. 설명란과 고정 댓글은 `업로드_정보.csv / .md`에 30편 모두 준비되어 있습니다. 겜토리처럼 고정 댓글에 "동물 이름 + 장소 + 구독 유도"를 넣습니다.
3. 반응 좋은 동물은 2편, 3편으로 시리즈화 (겜토리의 "무서운 장면 없는데 무서운 게임 2편" 전략).

## 6. 수익화까지의 현실

1. YouTube 파트너 프로그램(쇼츠 기준): 구독자 1,000명 + 최근 90일 쇼츠 조회수 1,000만 회. 또는 구독자 1,000명 + 긴 영상 시청 4,000시간.
2. 72시간 안에 수익화 승인까지 가는 것은 구조적으로 불가능합니다. 채널 개설·업로드·심사는 사용자 계정으로만 가능하고, 조회수가 쌓이는 데 시간이 필요합니다. 이번에 한 일은 그 출발점인 **채널 설계 + 자동 제작 공장 + 영상 30편** 입니다.
3. 심사 통과 가능성을 높이는 방법: 실제 사진 + 직접 쓴 스토리 + 자체 제작 음악 구성은 이미 갖췄습니다. 여기에 **본인 목소리 내레이션**을 얹으면 "재사용 콘텐츠" 판정 위험이 가장 낮아집니다.

## 7. 소재 확장 (다음 배치)

LILA BC에는 같은 방식으로 쓸 수 있는 데이터셋이 더 있습니다. 사용 전 데이터셋별 라이선스를 한 번씩 확인하세요.

1. Snapshot Safari (크루거 등 남아공 보호구역): 표범, 코뿔소, 들개
2. Idaho Camera Traps: 흑곰, 퓨마, 늑대, 무스
3. NZ Trailcams: 키위, 케아 앵무새
4. Orinoquía Camera Traps (콜롬비아): 재규어, 개미핥기, 맥
5. Snapshot Serengeti 자체도 아직 수천 개의 사건이 남아 있습니다 (새끼 동반 기록, 사냥 직후 기록, 희귀종 등).
